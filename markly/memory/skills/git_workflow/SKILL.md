# Git Workflow Skill

When interacting with git repositories, follow these rules:
1. **Never work on main directly**. Always create a branch.
2. Use descriptive commit messages.
3. Fetch before you pull.
4. If this skill is immutable, do not attempt to overwrite it using `skill.manage`.
